One registry fragment per kit module: <module>.tsv (e.g. human.tsv), same columns as ../message_codes.tsv (code, params, meaning_en, meaning_zh, meaning_zh-Hant: zh is Simplified, zh-Hant is written out by `python3 -m kit.zhconv fill`); only that module adds or edits its rows, and kit/messages.py loads every *.tsv here in sorted order after ../message_codes.tsv.
